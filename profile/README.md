# Mono Experimental

Development tools, experimental features, and staging environments for Monolythium.

## Repositories

| Repo | Description |
|------|-------------|
| [mono-core-dev](https://github.com/mono-experimental/mono-core-dev) | Development fork of mono-core for testing new features |
| [mono-evm-dev](https://github.com/mono-experimental/mono-evm-dev) | EVM compatibility layer development |
| [avalanche-network-runner-dev](https://github.com/mono-experimental/avalanche-network-runner-dev) | Local network testing infrastructure |
| [mono-cli](https://github.com/mono-experimental/mono-cli) | Command-line tools for developers |

## Purpose

This organization contains work-in-progress code, experimental features, and development tooling. Code here may be unstable and is not intended for production use.
